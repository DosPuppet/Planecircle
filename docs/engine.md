# The engine: file map and extension recipes

Pure, deterministic engine (`packages/engine/src`). The state is serializable; effects are data (the DSL), never functions.

## Files

| File | Role |
|---|---|
| `types.ts` | Base types (`Color`, `ManaCost`, `CardType`, `Keyword`, `RESTRICTIONS`) and mana abilities (`isManaAbility`, `isAnyManaAbility`, 605.1a); re-exports `model/*`. Always import from `types.ts`. |
| `model/cards.ts` | `CardDef` and its groups (`KickerDef`, `CastOption`, `CardRules`, `AdditionalCost`, `cda`), abilities (activated, triggered, static, mana, player, replacements, doublings), costs, `LayerMods`, `TokenSpec`, `MoveSpec`. |
| `cardDef.ts` | Lookups in the groups of a `CardDef` (PLAN-M M5): `castOption(d, kind)` (a cast option by kind), `cardRule(d, key)` (a printed card rule). |
| `model/rules.ts` | `ObjectFilter`, `TargetSpec`/`TargetFilter`, `TriggerSpec` (`on` union), `Condition`, `Ref`, `Amount`. |
| `model/effects.ts` | `Effect` (`op` union). |
| `model/state.ts` | `GameState`, `GameObject`, `PlayerState`, `StackItem`, combat, pending triggers, `LkiSnapshot`. |
| `model/decisions.ts` | Decisions, choices, action options, `GameEvent`. |
| `dsl.ts`, `dsl/*.ts` | Builders for card scripts: `fx.*`, `when.*`, `cond.*`, `amount.*`, `ref.*`, `target.*`, `activated`, `triggered`, `staticAbility`, `playerStatic`, `manaAbility`, `chapter`, `spree`, `tiered`… Plus `CardScript` (the fields of a card script). The `fx` builders are written by family in `dsl/fx-<domain>.ts` (the `ops/` domain of the op they build) and assembled into one `fx` object in `dsl.ts`; `ref.*` and `target.*` in `dsl/refs.ts`, `when.*` and `triggered` in `dsl/when.ts`. |
| `effects.ts` | `runEffect`: dispatch to the `op → handler` table (`opRegistry.ts`); `evalAmount` (`switch (a.kind)`); `resolveRef`; `evalCondition`; shared helpers (`store`, `damageSource`, `moveWithSpec`, `grantPlay`, `addEffect`…). |
| `ops/*.ts` | The effect handlers, by domain: `damage`, `players`, `counters`, `zones`, `spells` (stack, casting permissions), `permanents` (modifications, control, copies, tokens), `mana`, `flow` (if, choices, reflexive, delayed), `pay` (the "pay" family: "you may", "you may pay", "unless … pays", forage, collect evidence, behold, pay X). Each file exports `HANDLERS: OpHandlers`, registered by `ops/index.ts` in `opRegistry.ts` (imported by `game.ts`: effects.ts does not import the handlers, which keeps `ops/` out of the engine's import cycle). |
| `triggers.ts` | Trigger detection (`switch (t.on)` over `RulesEvent`), trigger doublings, `checkCondition` (`switch (c.kind)`), delayed abilities. |
| `stack.ts` | Casting (`castTerms`, `castableFaces`, `castSpell`), costs, activating (`activateAbility`, `canPayNonManaCost`), resolving, countering, playing a land; copies of spells and abilities (`copyStackItem`: a spell copy is an object on the stack). |
| `control.ts` | Layer 2: base controller (`baseController`), timestamped control effects (`addControlEffect`), Auras that give control. `syncControl` (`state.ts`, which calls it when a permanent leaves the battlefield) recomputes the controller of every permanent (state-based actions, cleanup, 800.4a). |
| `stackChoices.ts` | Choices about an item already on the stack, made before priority (`announceNext`): new targets of a copy (707.10c), division (601.2d, kept in `StackItem.division`). |
| `legal.ts` | `legalActions`: the options offered to players and to the AI (must mirror `stack.ts`). |
| `layers.ts` | Layers 613 (`chars`, cache keyed by `s.version` → `bump(s)`), 613.8 dependencies by fixed point (`collectStatics`, `applyLayers`), `copiedDefId` (active face, copy) and `copiableExceptions` (707.9b), `snapshot`/`view` (an object's view for filters). |
| `targets.ts` | `matchesView` (object filters), target legality and validation. |
| `actions.ts` | Damage (`dealDamage`: prevention, doubling, redirection), drawing, life, tokens, sacrifice. |
| `state.ts` | Objects, zones (`moveObject` and destination replacements), counters, `RulesEvent`, `setController`. |
| `modifiers.ts` | Replacements that modify a number ("that much plus N", "twice that many", "at least N"): order chosen for the affected player (616.1, `chooseReplacementOrder`). |
| `replacement.ts` | Enters replacements (`applyEntersReplacements`) and destination replacements (`replaceDestination`). |
| `turn.ts` | Steps, state-based actions (Sagas, Auras…), combat, elimination, extra turns and steps. |
| `mana.ts` | Mana abilities, payment solver, restricted mana. |
| `statics.ts` | Index of abilities by controller (`controlledAbilitiesWithSource`, `playerStatic`); quantified event replacements in force (`eventReplacements`, `quantityMods`, `recipientMatches`). |
| `view.ts` | Projection of the state for one player (hidden information). |
| `scenario.ts` | `createScenario`: a staged game (libraries in order, hands, permanents, starting turn, optional mulligan) for the tutorial; the empty state comes from `blankState` (`game.ts`). |
| `host.ts` | `GameHost`: AI, autopilot and humans; the `gate` option pauses the AI (tutorial explanations). |
| `game.ts` | Public API: `createGame`, `submit` (working copy, the received state is never modified), `applyMutable`; detection of mandatory-action loops (104.4b). |
| `choices.ts` | Generic choices: answer validation (`validateChoice`), request construction, `cardRef` (a card marker in a text, localized by the client). |
| `names.ts` | "Name" questions (`ChoiceRequest` of type `name`): the card-name catalog kept outside the state (`registerNameCatalog`), the official list of creature types (`CREATURE_TYPES`, 205.3m), accepted answers (`isNameAllowed`). |
| `autopilot.ts` | "Arena-style" autopilot: answers to trivial decisions (stops, full control, soft and hard passes); the engine itself stays strict. |
| `record.ts` | Game recording (seed, decks, decisions, checkpoints) and checked replay (`replayChecked`); `RULES_VERSION` and its history. |
| `fingerprint.ts` | `outcomeHash`: canonical fingerprint of a state, without internal identifiers (checkpoints, mandatory loops). |
| `decisionShape.ts` | Shape of a received decision (field types, unknown objects, duplicates), checked by `apply` (`game.ts`) before the rules. |
| `errors.ts` | `RulesError` and `rethrowAsRules`. |
| `events.ts` | Collector of display events (`collectEvents`, `emit`), dependency-free: any file can emit. |
| `limits.ts` | Safety caps (see below) and `capReached`. |
| `turnlog.ts` | Log of the turn's events (`s.turnLog`: public moves, spells cast, attacks, sacrifices, counters, activations, taps, mounts, damage, life gained and lost, draws, discards, scries, crimes, turned face up) and queries (`countTurnEvents`: count, `sum`, `distinct` values, including `distinct: "object"`: different creatures that attacked). "An opponent" (`who: "opponent"`): an opponent still in the game. Entries about one object (`id`: counters, activations, taps, discards, mounts, attacks): `objectTurnEvents`, `objectDidThisTurn`, `activatedThisTurn` (loyalty, 606.3; "once per turn"), `countersPutThisTurn`, through an index derived from the log and memoized per array (the log only grows during the turn). |

## Recipes

- **New effect:** add the `{ op: "…" }` variant to `Effect` (`model/effects.ts`), its handler `op(s, r, e, ctx, key) { … }` in the `HANDLERS` of the right `ops/<domain>.ts` file (`e` is typed by `op` there; `r` and `key` serve choices and stored variables), then its `fx.…` builder (`dsl/fx-<domain>.ts`). `cards/test/op-handlers.test.ts` fails on an op without a handler. If the effect changes characteristics, call `bump(s)`.
- **New trigger:** a `TriggerSpec` variant (`model/rules.ts`), a `case` in `triggers.ts` (return `{ objectId, player, amount }` for `ref.eventObject`, `ref.eventPlayer` and `amount.eventAmount`), then `when.…`. If the event does not exist, add a `RulesEvent` (`state.ts`) and emit it with `rulesEvent(s, …)`.
- **"… this turn" (counting what happened during the turn):** no new counter in `TurnStats` (reserved for counters specific to a rule: spell order, first piece…), no new `…ThisTurn` condition; use the turn log, `amount.turnEvents({ event, who, types, from, to, … })` (`turnlog.ts`), with `cond.amountAtLeast`; the source of damage is described with `source: { controller: "you", types, subtype, supertype, colors }`, compared by the same comparator as the entry's object (`charsMatch`). If an event or a field is missing, add it to `TurnLogEntry` (`model/state.ts`) and to its recording. **What an object did or underwent this turn** (loyalty ability activated, counters put on it, "the first time it becomes tapped this turn", discarded, mounted): never a `…Turn` field on `GameObject` (PLAN-H H11: none is left), but a log entry with its identifier (`id`), read by `objectDidThisTurn` or `objectTurnEvents`; an object that changes zones is a new object (400.7) and does not inherit the old one's entries. An entry read by a static or a filter must be recorded before the rules event whose triggers read it, and its filter key added to `scanDeps` (`layers.ts`, like `countersPutByYouThisTurn`).
- **Counting, summing, comparing objects:** no new kind of amount; `aggregate` (`fn`: sum, highest value, distinct values; `property`: power, toughness, mana value, color, type, subtype, name, counters…; objects of the filter, of a zone or designated by `of`) with the helpers `amount.totalPower`, `amount.maxManaValue`, `amount.colorsAmong`…, and one more `property` if needed (`propertyValues`, `effects.ts`). What was spent to cast a spell: `spent` (X, mana, colors, Caverns). "Each player / opponent who …": the `playersWhere` reference (condition evaluated from each player's point of view), with `refCount`.
- **"If it was cast …":** `cond.cast({ from, via })` (zone cast from, alternative cost: Web-slinging, chaos, sneak, evoke, warp, imminence); what was spent: `amount` `spent`. Everything is read from `CastInfo` (`castInfoOf`, `state.ts`: the stack item `StackItem.cast`, then the permanent `GameObject.cast`); a new piece of casting information goes there, not in a field of `StackItem` or `GameObject`.
- **New condition or new amount:** `Condition` + `checkCondition` + `cond.…`; `Amount` + `evalAmount` + `amount.…`. Two condition evaluators with distinct roles: `evalCondition` (`effects.ts`, during a resolution: targets, X, stored values) handles the kinds that depend on those and delegates the others to `checkCondition` (`triggers.ts`, outside a resolution: statics, triggers, costs); a few kinds exist in both with semantics specific to each moment (`refMatches` outside a resolution reads the event's object). A context outside a resolution is always built with `staticContext` (`effects.ts`). An amount used in a P/T defined by an ability or a `perAmount` must be in `CDA_AMOUNT_KINDS` (`layers.ts`, `cdaValue`; an aggregate by its `cdaKey`), which `cards/test/cda.test.ts` checks.
- **Object filter:** a field of `ObjectFilter`, computed in `view()` (`layers.ts`) if needed, and tested in `matchesView` (`targets.ts`). **Dynamic comparison** ("with power greater than that creature's", "with mana value X or less", "whose toughness is greater than its power", PLAN-H H10): never a new `…X` or `…Source` field, but an entry of `compare` (`FilterCompare`: `what` power, toughness or mana value; `cmp` `<`, `<=`, `=`, `>=`, `>`, or `odd` / `even` for parity; `to` an amount, or `"power"` / `"basePower"` of the object itself), written with the helpers `cmp.power`, `cmp.toughness`, `cmp.manaValue`, `cmp.parity` (`dsl.ts`): `{ types: ["Creature"], compare: [cmp.manaValue("<=", amount.x)] }`. Fixed bounds stay `minPower`, `maxManaValue`… A single resolver, `resolveCompare` (`effects.ts`), replaces each amount with its value: during a resolution (`withX`, zone references, `moveAll`, search), with the context of what is resolving (the X read is the ability's or the spell's); elsewhere (`resolveFilter`: targets, statics, triggers, permissions), from the source's point of view alone (the X read is the permanent's, the X of the spell that put it onto the battlefield). An unresolved amount (a filter read directly by `matchesView`) is ignored. The source's values are read without a floor (107.1b) with the `raw` amount: `amount.sourcePower` (on the battlefield, otherwise from its last known information), `amount.sourceManaSpent`, `amount.rawPowerOf(ref)`; its counters: `amount.lkiCounters(kind)`; its colors spent: `amount.colorsSpent`. **Attachments and crew:** `attached` (`"host"`: the permanent the source is attached to; `"notHost"`; `"toSource"`: attached to the source; `"toHost"`: attached to the same permanent as it; `"wasToSource"`: was attached to it when it left), `crew` (`"bySource"`: a Vehicle it crewed this turn; `"source"`: a creature that crewed or saddled it). The reference `ref.attached` designates the permanent the source is attached to; with `of` (`ref.hostOf(r)`), the permanents the designated objects are attached to (Eriette: the host of the Aura of the event). **"Whenever [an Aura, this Equipment] becomes attached …, for as long as it remains attached":** `TriggerSpec.becomesAttached` (`who`: a filter or `"self"`), then an effect with the `whileAttached` duration and its `attachment` (`gainControl`: Eriette; `becomeCopy`: Assimilation Aegis); `endDetachedEffects` (`state.ts`) ends it as soon as the attachment leaves or moves (`attach`, `unattach`, `syncControl`). A static copy of the linked exiled card (`copyLinkedExile`) stays for "until this Aura leaves the battlefield" (Secret Invasion).
- **Player static:** a field of `PlayerStaticAbilityDef` (only if no generic form fits: rule at the end of CLAUDE.md), read with `playerStatic`, `playerStaticTotal` or `playerStatics(s, p, "key")` (`statics.ts`), which check the condition and count the effects on players. Never by filtering `controlledAbilitiesWithSource` on `kind === "playerStatic"`. A field with several values has a single evaluator (PLAN-H, H8b): `cantLose(s, p, "life"?)` (`cantLose: true | "life"`), `skips(s, p, what)` (`skips: "turn" | "drawStep" | "extraTurns"`), `damageUnpreventable(s, combat)` (`true | "combat"`), `mayLookAt(s, player, object)` (`lookAt: "libraryTop" | "faceDown"`, `view.ts`'s only access to hidden information that a static reveals), `maxHandSize` (`Amount | "none"`, `turn.ts`), `attackableDefenders` (`cantAttack: { of, subtype? }`). A new value goes through the field's evaluator, never through a new neighboring field.
- **Restriction, technical keyword:** add to `Keyword` and `RESTRICTIONS` (`types.ts`), with its label in `client/src/i18n.ts` (otherwise `tsc` fails). Not for what a generic form expresses: "prevent all combat damage that would be dealt to it" is a `prevention({ self: true }, { combatOnly: true })` (Diamond Weapon); "doesn't untap during its controller's untap step" is `doesntUntap(affects, { may, condition })` (`dsl.ts`), below.
- **Untapping (502.3):** "can't be untapped": `eventReplacement({ event: "untap", toFilter, modify: { prevent: true } })`, read by `untapObject` (Blossombind); "doesn't untap during its controller's untap step": `doesntUntap("self" | "attached" | filter)`, the same replacement with `untapStep: true`, read only by the untap step (`untapStepRule`, `statics.ts`; an effect or Prop Room can untap it); granted by an effect: `addAbilities: [doesntUntap("self")]` (Ty Lee). "You may choose not to untap it": `doesntUntap("self", { may: true })` (`untapStep: "may"`): the untap step asks the active player a question (`ChoicePurpose` `untap`, `answerUntapStep`, `turn.ts`) when such a permanent is tapped; suggested answer: keep it tapped while an effect lasts "for as long as it remains tapped" (Hedge Whisperer). The AI reads `staysTapped` (`ai/src/evaluate.ts`); the view, `ObjectView.untapRule` (the client's restriction badge).
- **"As enters" (614.1c, 614.12, PLAN-H H9):** `CardDef.asEnters: Effect[]`, done while the permanent enters, before the enters event: choices `fx.chooseForSelf(kind, { options })` (creature type, color, name, mode, number, parity, basic land type; `options` restricts the choices), `fx.chooseCopy(filter, { anyController, fromGraveyards, optional, duration, except, counters, tapped, exile })` ("enters as a copy", 707.9; `except`: copiable exceptions, 707.9b; `counters` and `tapped`: only if it copies), `fx.devour(filter, n)` (devour, read from the text); any other effect too (Sin: `chooseAmong` then `removeCounters`), with its stored values; counters put on `ref.self` (`fx.addCounters`, `fx.counters`) are the ones it enters with; `fx.moveTo(ref.self, { to: "graveyard" })` keeps it from entering (Mox Diamond). **A single loop**, `asEntersChoices` (`replacement.ts`), for the four paths: a permanent spell that resolves (internal operation `asEnters`, added by `specsAndEffects`; a copy of a permanent spell too, 707.10), a land played (`playLand`: the first question comes with the decision, `chosen` or `landType`, offered by `legalActions` in `probe` mode; `""` for "none"), an effect that puts it onto the battlefield (`arrivalChoices`, `ops/zones.ts`), any other entering (`applyEntersReplacements`, `default` mode: the choices only, with the suggestion). Riot (702.136) is also asked there; a copy then makes the "as enters" choices of its model (707.9, without a second copy); a face-down permanent has none (708.2). Each finished effect is noted in the resolution's variables (replaying the loop does not redo it); the result (`EntersChoices`: `chosen`, `copyOf`, `copyMods`, `copyDuration`, `counters`, `tapped`, `linked`, `exileCopied`, `riot`) goes into `EntersContext` (`withEntersChoices`). The activated abilities of sources with the chosen name: `rules.chosenNameAbilities` (`N` more, or `"forbid"`). **Names (201.3, 709.4, 715.4, 712.8a):** the computed name (`chars(s, id).name`) is the name of the face in use, otherwise `printedName` (front face of a double-faced card, main name of an adventurer; "A // B" for a split card); every comparison goes through `names.ts` (`hasName`, `shareName`, `firstOfEachName`, `nameList`), never `def.name ===`; "A // B" is not a name that can be chosen (`isSingleName`, catalog).
- **Naming a card, a land card, a creature type** (`chooseForSelf("cardName" | "landName" | "creatureType")` without `options`, `fx.chooseCardName`): a question of type `name` (`nameRequest`, `ops/permanents.ts`), **never a list drawn from `s.defs`** (it contains the cards of every deck: the opponent's decklist). `featured`: public names (opposing permanents, then yours, then graveyards, face-up exile, command zone; creature types: the most common among your cards, then those of the creatures in play); `suggested` (the AI answers it) is the first of them. Accepted answer (`isNameAllowed`, `names.ts`): a name from the catalog (`registerNameCatalog(nameCatalog())`, outside the state: server at startup (`RoomManager`), interface and worker (`names` message), tests) or, for types, from `CREATURE_TYPES`; a name from the game always is (games recorded before the catalog, tests without a catalog). The question never depends on the catalog (determinism). The interface (`NameSearch`, `client/src/names.ts`) searches the whole catalog, French names first, and sends the English name.
- **Card script field:** in `CardScript` (`dsl.ts`), `CardDef` (`model/cards.ts`) and the copy in `singleDef` (`cards/src/scryfall.ts`). A `CardDef` field goes into its group when it belongs to one (PLAN-M M5): a way to cast the card in `castOptions` (a `CastOption` variant by `kind`: `flashback` with its `extra` costs and `harmonize`, `graveyard`, `mayhem`, `madness`, `warp`, `plot`, `foretell`, `flash`, `alternative` with its `via`, `faceDown`), read by `castOption(d, kind)` (`cardDef.ts`), never by position in the list; a printed rule of the card in `rules` (`CardRules`: can't be countered or copied, exiled on resolution, flash as long as…, cast condition…), read by `cardRule(d, key)`; an optional cost paid like a kicker in `kicker` (`KickerDef`: `mana`, `kind`, `pay`, `orPay`, `gift`); a cost of the spell in `additionalCost` (also X paid other than with mana, `xCost`; waterbend; "forage or pay"; the surcharge per extra target); a P/T defined by an ability in `cda` (`pt`, `power`, `toughness`). `CardScript` still has the former flat keys (`flashback`, `altCost`, `cantBeCountered`…), which `singleDef` translates, until it is derived from `CardDef` (PLAN-M M12). `KickerDef`, `CardRules` and the `CastOption` union are measured by the debt guard (`debtSurface.ts`; a single-card `kind` of `CastOption` is a `variant` entry).
- **Mana ability with a cost ("{1}, {T}: Add one mana of any color"):** an ordinary `activated` ability is enough; `isManaAbility` (605.1a) resolves it without the stack.
- **Replacement that modifies a number** (damage, counters, life, draw): add it as an `AmountMod` (`add`, `times`, `atLeast`) in the event's list (`dealDamage`, `changeCounters`, `gainLife`, `drawCards`), never by modifying the quantity directly; the order is chosen by `chooseReplacementOrder`. A draw goes through `drawCards` (except the opening hand).
- **Damage and life loss: replacements and prevention** (R1, families E and F): an `eventReplacement({ event: "damage" | "lifeLoss", source, to, toFilter, combat, modify: { add, times, atLeast, prevent }, onPrevent, condition })` ability, or a `fx.thisTurn({ replacement })` effect; "the next time" shield: `fx.shield(replacement, sourceChoice)`. Collector: `eventReplacements` (`statics.ts`); application: `dealDamage` and `loseLife` (`actions.ts`), prevention by a player other than the damaged one before the modifications, the player's own after (616.1). `add` and `atLeast` are amounts, evaluated from the replacement's point of view (`ref.self`: its source; `replacementAdd`, `replacementAtLeast`): `amount.powerOf(ref.self)` (Hawkeye, Ojer Axonil), `amount.countersOn(ref.self, "fire")` (Fated Firepower).
- **"If [an object] would be put into a graveyard, exile it instead":** a `graveyardReplacement({ filter, fromBattlefield, graveyardOf, notControlledByYou, link, gainLife, condition })` ability, and not a `playerStatic` flag. The order of 616.1 is applied by `replaceGraveyard` (`replacement.ts`), called by `moveObject`.
- **"You may cast [this card]" during a resolution (608.2g):** `fx.castNow(ref, { free, many, after, anyMana, storeCast, storeRest })` (`after`: `"exile"` or `"bottom"`, instead of the graveyard), and not `fx.grantPlay` (which leaves the card castable later in the turn). From an effect handler, the `castNowLoop` loop (`ops/spells.ts`) returns `{ castNow: … }`, which suspends the resolution on a restricted priority (`PendingDecision.castNow`).
- **Effect on a player until end of turn** ("damage can't be prevented this turn"): `fx.thisTurn({ key: value })`, with a `PlayerStaticAbilityDef` key already read by the engine; no new effect. Other durations: `duration` of `playerEffect` (`untilYourNextTurn`, `untilTheirNextTurn`, `forever`; helpers `fx.untilYourNextTurn`, `fx.untilTheirNextTurn`).
- **Durations and fate of copies (PLAN-H H7a):** a `modify` effect that lasts "for as long as…" carries `while` (`ModifyWhile`: `"source"`, `"sourceTapped"`, `"youControlSource"`, `"tapped"`, `{ counter }`, `{ exiled }`; helpers `fx.modifyWhileSource`, `modifyWhileTapped`, `modifyWhileCounter`…); the fate of copy tokens, `copyToken.atEnd` (`CopyFate`: `"sacrifice"`, `"exile"` at the next end step, or `{ fate, at: "endOfCombat" | "nextUpkeep" }`: "sacrifice it at the beginning of the next end step"); a token that *has* "At the beginning of the end step, sacrifice this token" gets the ability `SACRIFICE_TOKEN_AT_END_STEP` (`copyToken` `addAbilities`; the token copy of a creature spell, `copySpell.atEnd: "sacrifice"`, gains it; PLAN-M M7); the duration of a permission to play, `grantPlay.duration` (`untilYourNextTurn`, `untilOwnersNextTurn`, `untilYourNextEndStep`, `forever`); face down on entering, `MoveSpec.as` (`"cloak"` or `"manifest"`). The DSL helpers keep their options (`sacrificeAtEndStep`, `forever`…) and translate them.
- **Cost paid with objects** (blight, collect evidence, exiling from the graveyard, sacrificing X, convoke…): a `CostSlot` (`model/decisions.ts`) described in `activationPicks` (abilities) or `spellPicks` (spells), in `stack.ts`, with its options and its suggestion (the engine's choice); at payment, `pickNow` / `spellPickNow` apply the player's choice (`CastChoices.picks`, checked by `resolvePick`) or the suggestion. `legalActions` publishes the slots where the player has a choice (`ActionOption.picks`, filtered by `pickHasChoice`: never a question with a single possible answer), and the interface asks for them (`CostPickPicker`). Never an object choice hard-coded in `castSpell` or `activateAbility`: the former automatic function becomes the slot's `suggested`, so the AI (which sends no picks) and the golden games keep their choice. Slot forms (PLAN-M M6): `when: "alternative"` / `"kicked"` (only with that cost: `altCostPicks` for Force of Will, Daze, the Flares, emerge — `spellCost` reads the chosen victim); options that are labels, not objects (`LABEL_SLOTS`: `counterKind`, `permanentType`, `freeCost`; `labels` gives their text, checked by the payment, not by `decisionShape`); a kind of counter on an object (`id:kind`, `counterKindOptions`; a bare `id` keeps the default kind, `resolvePick` checks the total per object); `oneOf` groups (forage: three graveyard cards or a Food); `minTotal` (evidence, Zemo's symbols) with `fromTargets` when the total is the targets' mana value (the interface computes it once the targets are chosen); `autoOk` for a payment detail (Kíli's {0}, the permanent tapped by Gene Pollinator: `tapForMana.picks.costTap`, `tapAnotherPick`), asked only in full control. The strict fuzz (`checkOffers`) submits the last options of each slot without `when`, `countIsX`, `repeat` or `atMost`: every option listed must be accepted. Permanents tapped to help pay an ability's mana: `CostDef.tapToPay` (`"waterbend"`: artifacts and creatures, {1} each; `"convoke"`: Heirloom Epic), written with the `waterbend` and `convoke` options of `activated`.
- **Paying during a resolution (the "pay" family, PLAN-M M4):** one `pay` op (`ops/pay.ts`), its `cost` a `PayCost` (a `Pick` of `CostDef`: mana, life, sacrifice, discard, collect evidence, forage, exile, behold, poison, `tapToPay`). The handler dispatches by shape (unless → `manaOf` → `totalManaValue` → evidence → chosen X → forage → behold → mana or life → may) to the bodies of the former ops, which keep their question keys (`unless`, `unlessHow`, `unlessCard`, `unlessSac`, `pay`, `paycost`, `payx`, `forage`, `x`, `may`, `evidence`, `behold`), options, intents (`unlessPay`, `payX`, `may`…) and prompts. A new "you may pay …" form: a field of `PayCost` (from `CostDef`) and a branch of the handler, never a new op. The text of an "unless" cost and of the ward badge: `payCostText` (`mana.ts`).
- **Alternative cost that changes the text** (overload, fuse): a second mode cast for its own cost, `ModeDef.cost` (helper `altCostMode`); never free nor with another alternative cost (118.9a). Escalate: `escalate(cost, …modes)`, all the combinations with their extra cost, like `spree`. An alternative cost that other rules read carries its name in the `via` of the `alternative` cast option (`CastInfo.via` at cast time; evoke, sneak, web-slinging, impending, dash: haste and return to hand, read by `cond.castVia("dash")`); dash, blitz (`via: "blitz"`: haste, the draw on death and the sacrifice come from the cast, `stack.ts`) and spectacle are deduced from the text (`scryfall.ts`).

- **Player static that affects other players** ("players can't gain life"): `playerStatic({ …, affects: "each" | "opponents" | "enchanted" })` (`enchanted`: the player the source enchants, Grievous Wound); the static is filed for each player concerned (`affectedPlayers`, `statics.ts`). - **"Keep the chosen permanents, sacrifice (or destroy) the rest"** (PLAN-H H8a): a single operation, `keep` (`fx.keep(players, pick, filter, { chooser, fate, among, max })`, `ops/zones.ts`). The choices are made first, in APNAP order, by each player (`chooser: "each"`: Liliana, Dreadhorde General, Destined Confrontation) or by you for each one (`"you"`: Tragic Arrogance, Winnowing, Unstable Glyphbridge); then the fate (`fate`: `"sacrifice"` or `"destroy"`) falls at the same time on all the other permanents of the filter. `pick`: `"one"`, `"onePerType"` (a permanent with several types can be chosen for each; the types of `among` bound those one chooses), `"totalPower"` (total power `max` or less), `"sharesType"` (those sharing a creature type with the chosen one are kept too); `among`: those that can be chosen, if they differ from the filter. Never a question for a single option. - **Vivi Ornitier deck (rules 176):** **soulbond** (702.95): `GameObject.pairedWith` (on both creatures), `fx.pair(a, b)` (only two unpaired creatures of the controller), filter `paired` (`true`, `false`, or `"source"`: the source while paired and its partner, for "each of those creatures has …"), the two abilities read from the text (`soulbondAbilities`, `dsl.ts`), the pair broken by the state-based checks (`stateBasedActionsOnce`). **Transmute** (702.53): read from the text (`parseTransmute`, `scryfall.ts`). **"Look at" cards**: `fx.look(ref, random?)` emits a `reveal` event with `look`, sent only to the looking player (`filterEvents`). **"Copy this spell"** while it resolves: `copySpell` finds the spell by its card (`ref.self`); `for`: another player copies it and controls the copy (Chain of Vapor). **New targets of a copy** (707.10c): targets that no longer exist may be replaced (`retargetRequest`: `max` above `min`, kept by default). **"Any number" with a maximum**: `chooseAmong(…, { anyNumber, max })` (Intuition). **"Target spell with a single target"**: `stackItems: { singleTarget, spellsOnly }`.

## Safety caps

Guards keep a game from looping or exploding; they declare the game a draw or cut an amount. All the constants are in `limits.ts`; a cut emits the `capReached` event (game log) and the fuzz counts the cuts ("caps reached").

| Cap | Where | Value | Effect |
|---|---|---|---|
| Steps of the run | `turn.ts` | 100,000 | game is a draw |
| State-based action passes | `turn.ts` | 100 | game is a draw |
| Mandatory-action loop (104.4b) | `game.ts` | same fingerprint 3 times; or same fingerprint where tokens and stack objects count only once, 3 times, with neither the stack nor the battlefield shrinking (a loop that accumulates: Ganax and Draconic Visitor); the choices made during the loop (trigger order, targets) do not cut it | game is a draw |
| Automatic decisions per turn | `host.ts` | 10,000 | game is a draw |
| Tokens created | `actions.ts` | 100 per event, none beyond 400 objects | cut |
| Replaced amount | `modifiers.ts` | 1,000,000 | cut |
| Announced X (spells, abilities, squad and replicate) | `stack.ts` | 1,000,000 | decision refused |
| Order of quantified replacements | `modifiers.ts` | 5 replacements | code order beyond that |
| Layer passes (613.8) | `layers.ts` | 3 | fixed point stops |

Any new cap goes in `limits.ts`, in this table and in `docs/approximations.md`.

## Design rules

- **Errors:**
  - an illegal or malformed decision raises a `RulesError` (the AI, the server and the fuzz depend on it);
  - any other `Error` is an engine bug;
  - never convert an arbitrary error into a `RulesError`. Around a step that may be illegal (payment, targets), go through `rethrowAsRules(e, message)`, which lets other errors propagate;
  - the AI swallows only `RulesError`s in its simulations;
  - the "chaos" fuzz (`npm run fuzz -- --ai chaos`) submits corrupted variants of each decision: they must be refused with a `RulesError`, without modifying the received state.
- **Fuzz invariants** (`checkInvariants`, `ai/src/selfplay.ts`):
  - zones, conservation of cards, layers cache;
  - finite numbers;
  - references (attachments, combatants);
  - no decision requested from an eliminated player;
  - state is pure JSON.
  
  A new state field must respect them.
- Everything a static or a variable P/T depends on advances the state version (`bump`). The fuzz detects omissions ("stale characteristics cache").
- **Targeted invalidation** (`bumpFor`, `layers.ts`): tapping, untapping and paying mana invalidate the cache only if a static, an effect or an ability-defined P/T in force reads the tapped state (`tapped` key of a filter) or the pool (`manaPoolAtLeast`); likewise for the turn log (`turnLog`), life totals (`life`: `perLife`, `lifeTotal`, `mostLife`, `refLife`, `opponentHasMore` of life) and the damage already dealt by a source (`dealt`: `sourceDealtDamage`, `sourceDealtCombatDamage`). A key present without a value does not count. A new form that reads one of them in another way must be added to `scanDeps`; any other modification read by a static (a player's poison or rad counters…) does a `bump`. The fuzz compares the cache to a fresh computation at each decision (`checkInvariants`). During a computation of the layers and of the trigger sources, the traversal context (`withScan`: equipped, enchanted, the copies table `copiedDefMap`) is computed once. The indexes that follow the version (`statics.ts`: player statics by key, replacements by event; `triggers.ts`: trigger sources, whose key also carries the composition of the zones and the tapped permanents) are recomputed with it.
- No new flag, keyword, operation, property or field specific to one card without justification: rule at the end of CLAUDE.md, checked by `cards/test/debt.test.ts` (reference `cards/data/debt-baseline.json`). The test also tracks the size of each model surface (`ceilings`: fields of `CardDef`, `GameObject`, `ObjectFilter`…, variants of `Effect`, `Amount`, `Condition`…), the "this turn" fields of `GameObject`, the card names written in the engine code and the largest import cycle (`importCycleMax`): none may grow without the reference being modified in the lot.
- Prefer a generic, named mechanism to a flag "for one card":
  - reuse the quantified event replacements (`eventReplacement`: damage, life loss and gain, draw, mill, counters, tokens, mana, untap; R1) and the trigger multipliers (`triggers.ts`);
  - reuse the casting permissions (`grantPlay`, `castTerms`) and the modifications on entering (`StackItem.arrival`).
- An ability of a permanent deals its damage with that permanent as the source (`damageSource`).
- Card scripts go in `packages/cards/src/<ext>/`. The texts of missing cards are obtained with `npm run coverage -- --set <ext> --text`.
